## 指标定义

| 指标 | 计算与分母 | 判读要求 |
|---|---|---|
| 平衡准确率 | 两类召回率的平均，阈值在开发集固定 | 与普通准确率分开报告；单类测试不能计算完整结果 |
| Macro F1 | 每类 F1 的等权平均 | 是后续统一对照的补充项，不能把现有其他 F1 口径直接改名 |
| AUROC | 同时具有两类标签的参与者先各自计算，再等权平均；另报合并样本结果 | AUROC 不是正确率；保留人数和每人有效标签数 |
| AP | 由连续分数计算平均精确率，并报告正类比例 | 与梯形 PR AUC 分开命名 |
| EEG 覆盖率 | 有合格 EEG 与二分类标签的正式探针数／全部有有效二分类标签的正式探针数 | 同时报告未作答、模糊标签和未完成记录，不只展示可评分子集 |
| 有效信号时长 | 合格窗口时间区间的并集 | 重叠的四秒窗不能重复累加为八秒 |
| 脑电增量 | 同一测试参与者和探针上，融合模型减匹配的无 EEG 模型 | 保持行为／时间变量与校准预算相同，报告按人配对区间 |
| 误报与响应 | 经独立事件标注的误报次数／有效监测小时，及状态变化到输出的延迟 | 目前属于待现场测量项；无独立真值时只能报告触发次数 |
| 运行成本 | 指定设备上的推断 p50/p95、内存、模型大小、更新周期、输入跨度 | 分开报告传输、计算、滤波与显示耗时；不要由前向时间推断状态响应时间 |

现有真人训练说明中的 AUROC≥0.70、区间下界>0.60、覆盖≥70% 是内部研发目标，参见 [训练说明](../ningsi-studio/docs/HUMAN_MODEL_TRAINING.md)。它们不是比赛规定，达到单项也不能替代独立人群和设备验证。

| 路线 | 当前状态 | 下一次比较条件 |
|---|---|---|
| B0 频谱与个人基线 | 已有频带功率、比值、基线与相对指数 | 固定基线来源，报告原指数与阈值方向 |
| B1 特征模型 | 已有本地逻辑回归与冻结公共 RBF 等研究候选 | 同一标签、样本、人员划分；新 SVM／随机森林先在开发集选择 |
| B2 EEGNet | 尚未接入生产链路 | 同一通道、采样率、有效窗口和划分；另记录原始矩阵输入与训练成本 |
| 无 EEG 对照 | 研究已有任务时间、序号、行为及个人历史等对照 | 依任务定义匹配，和融合模型使用相同历史标签与校准预算 |

不能将不同公共研究的最高准确率放在同一排名表中作为产品性能。个人校准量研究已显示，更多早期 EEG 与标签提高覆盖或某些融合结果，并不稳定地提高相对匹配纯行为／自评模型的增益；后续优先检验目标设备与新人的增量价值。

## 现场验收顺序

1. **先验证采集。** 核对实际电极位置、参考、设备型号与单位；保存源时间戳，记录所选时标策略及其可验证范围。用完整原始记录确认掉线、时钟重置、短历史与单位冲突能被发现。
2. **再验证质量。** 保留自然任务片段，另标记眨眼、皱眉、咬牙、转头、闭眼动作。分别检查正确拒绝、误拒绝和漏检；不以分数升降本身充当污染真值。
3. **再采独立标签。** 使用既定 SART／PVT、随机探针与明确时间的自评。练习、预试、模糊回答与未完成记录保留排除原因。背景模型预测不改变探针和答案。
4. **冻结再测试。** 按人固定开发／测试名单，将同人所有到访放在同组；个人模型另固定校准前段和后测，间隔覆盖全部滤波历史与特征回看。校准与阈值选择结束后再打开测试数据。
5. **检查重新佩戴与任务迁移。** 同人新时间段、跨天复测、新人和新任务分别统计。训练前后变化先描述；强化训练效果需匹配对照和独立行为结果。
6. **同步交付材料。** 架构、参数、软件版本、人员分母与结果区间统一后，再更新 DOCX、PPT、演示和赛事归档；历史包保持可追溯。

## 持续优化顺序

本轮完成共享逐窗服务、包依赖约束和架构说明。下一轮优先取得目标设备的完整合格基线、独立探针和跨天记录；再比较固定数据上的 B0、B1 与匹配无 EEG 对照。B2 和多通道分离方法在输入条件与数据量具备后接入。任何预处理迁移都先建立新版本契约与旧产物兼容验证，再改变默认配置。

原始流未提供实际电极位置、参考电极及电压单位字段；本地 BioMulti 软件的数据路径支持以 µV 解释原始值，但这属于软件依据，不能替代硬件标定或证明真人佩戴。原始记录、诊断和匿名运行数据仅保留本机 `var/`，不进入源代码提交及发行包。独立同步录制、可用真人基线、三类状态独立验证及反馈效果仍需后续现场证据。

## 状态热力图的可用性与评分分离

Studio 0.1.11 修正两处展示问题：未建立基线的合格信号曾被统一标成“低质量缺失”；十分钟协议的训练窗曾没有纳入热力图。新版单独保存热力图窗口及质量依据，区分有评分、基线待确认、信号受限、完整数据不足、时标问题和未知原因。训练窗进入热力图，不混入独立评估或历史趋势的指标汇总。

窗口在 REST、SSE 和 SVG 导出使用同一可用性分类。旧记录优先从已有诊断只读恢复，缺少依据时保留未知原因；不补造基线、质量或分数。回放一条既有模拟记录可恢复 100 个遗漏的训练评分窗，合计 175 个信号合格窗，其中 130 窗已有评分、45 窗处于评分前准备阶段。这是软件回放结果，不代表新增真人有效脑电。

网页增加全会话覆盖摘要、受限原因、每页 120 窗和仅看可评分片段；筛选后仍显示完整分母。无评分时默认收起逐窗网格，保留原因和操作提示。时间为分析窗口步进，未采集的行为阶段不补窗，重叠窗数不换算为连续有效时长。历史窗口计数和终态错误提示在服务重启后继续保留。

## 有效时长训练与坏窗影响控制

Studio 0.1.12 新增独立 `effective_time` 协议，原固定协议仍保留。前后基线各以完整合格窗口的时间并集累计 60 秒，分别最多调度 180 秒；基线构建仍使用全部候选窗口，保留原有质量比例和最短基线要求。训练 4 轮分别累计 50 秒可用反馈、最多调度 100 秒，每轮休息 10 秒；初始基线无效时每轮保持原 50 秒固定引导并记录不足。练习 30 秒及 PVT 180 秒保持固定，总采集调度上限 1040 秒，不包括连接、报告及输入阻塞额外用时，实际时间保留。

反馈只累计发布后实际经过且有依据的区间，最多支持到下一次 2 秒更新；没有信号的空隙不插值，取消时不提前记入未来时间。独立核对实时累计与段末统计，一致且达到目标才算完成。累计进度可以保留，连续保持遇无效窗口断开；达标表现按有效反馈时间计算，覆盖率、有效秒数和完整用时另行显示。缺失不填零、不中途复用旧分数，覆盖不足保留“不足”结论。模拟协议秒与真实墙钟时间分列。

分析处理产生的反馈到期间隙单独记为支持期中断，不充作新的 EEG 排除窗口。确定性 0.5 秒分析延迟用例中，67.5 秒段时长保留 50 秒有效反馈，最长连续保持不超过 2 秒，未触发错误目标上调；实时累计与持久化统计一致。取消尾部及输入延迟越过调度上限也保留真实时间和中断。

局部伪迹仅增加离线审计工具，不进入生产评分。三段既有现场导出按重叠窗口掩码并集、有限滤波支撑区保护后，得到描述性剩余覆盖约 3.10、0、0 秒；窗口外新增覆盖和连续 4 秒候选均为 0。去掉保护会提高名义覆盖，但相邻窗口对边界的判定不一致，尚不能证明为干净脑电。本轮没有据此放宽阈值或训练模型。

本轮完整回归运行 619 项用例：616 项通过，3 项可选检查跳过（脚本 40、引擎 102、Studio 366、Capture 111）。随后将含糊的“达标状态”改为“连续保持状态”，相关 11 项前端测试再次通过。最终 Windows 构建通过 35 项冻结验收，覆盖原固定协议、新协议全流程、有效区间与真实分母对账、模拟时间分列、报告与 ZIP 校验。浏览器核对有效时长入口、保存后统计、连续保持标注及前端布局。原工作台无活动会话时已备份并加载新版，既有四条会话状态保留；新的软件测试全部使用隔离的模拟数据，不代表新增真人全流程、识别或疗效验证。
