凝思目标设备现场验收清单
版本日期：2026-11-17
用途：收集可追溯证据。未勾选或缺失应记“待完成”，不自动签发合规、准确率或训练有效结论。

一、准备一份新的记录
[ ] 使用匿名参与者编号、访次和预先固定的开发/封存测试分组；同人的所有到访属于同组。
[ ] 明确实际运行的 Studio/Capture/引擎版本、构建提交或源码哈希。
[ ] 保存设备厂家、完整型号、固件/厂商程序版本、实际电极、参考与地、采样率、单位和换算依据。
[ ] 区分 EEG、EOG、EMG、运动参考；两条前额 EEG 不自动记为 EOG。
[ ] 按既定研究流程完成告知和记录安排；现场操作只按设备厂商允许的方式进行。
[ ] 新建数据目录，保留原记录；不把预试、模拟或未完成会话混入正式数据。

二、先确认采集与环境
[ ] 厂商程序确认设备和导联；源名/source_id与 Studio 选择一致，模拟源单独标识。
[ ] 按厂商说明检查接触、参考/地与连接；单位必须有配置或标定依据，不能用“看起来正常”的倍率。
[ ] 先保存自然静息原始片段，检查平线、饱和、突跳、峰峰值和原始 PSD。
[ ] 若原始工频占主导，每次只改变一项并另存片段：重新确认接触/参考、调整线缆或环境设备位置、按厂商允许的安全供电方式复测。
[ ] 不通过放宽质量阈值、隐藏工频或删掉困难片段宣告采集通过。

三、使用成熟工具并行留证
[ ] LabRecorder选择明确的EEG流保存XDF；若另有任务Marker出口则同时选择，不能将未发布的事件当作已录入XDF。本产品仍按原方案连续记录。
[ ] Capture 0.4.1可在“外部同步”显式开启Marker（默认关闭，也可gui --lsl-markers）；先开始采集，等LabRecorder发现对应流并开始录制，再打开受试者任务。
[ ] Capture事件完整保存在自身数据库/导出的time_lsl；Marker仅含事件编号/阶段等白名单，不含答案。回环测试通过不代表实际XDF已经包含全部任务段，仍须独立打开核查。
[ ] 记录 LabRecorder/liblsl/pyxdf 版本、流描述与选用同步/去抖选项。
[ ] 保存原始源时间戳、接收时刻和本产品分析时标；不要只保留拟合后的时间线。
[ ] BioMulti原生REC双录按既有流程核对样点与分包，结果不替代普通在线LSL的时间依据。
[ ] 掉线、重连、时钟重置和任务事件分别有时间标记；间断没有用补点伪装成连续数据。
[ ] 仅有软件时标时，物理显示/键盘/设备传输延迟写“未验证”；测物理延迟需独立同步触发或光电等方案。

四、质量门与伪迹对照
[ ] 自然任务片段与动作对照片段分开标记；眨眼、咬牙、转头等按预定顺序记录。
[ ] 保存动作标记来源，检查正确拒绝、误拒和漏检，不用状态分数本身作污染真值。
[ ] 保存原始、滤后与掩码；陷波抑制只说明滤波响应，不表示恢复了无污染脑电。
[ ] 基线达到当前协议的独立有效时长和质量要求；有效时长按窗口时间区间并集统计。
[ ] 未达到基线时保留诊断/独立行为结果，停止相对评分，记录调整原因和是否重采。
[ ] 使用 scripts/audit_field_signal.py 的独立 MNE 审计；工具参数见 --help，依赖见 scripts/requirements-field-audit.txt。

五、完整任务与模型
[ ] 实际完成所选协议、练习/正式阶段、基线、任务、探针回答和研究导出。
[ ] 探针没有由模型改变时机或答案；练习、模糊/缺失回答和未完成记录有排除原因。
[ ] 区分全部探针、有效二分类回答、配有合格EEG的探针、可训练行、可测试行，保留每个分母。
[ ] 两类标签或有效参与者不足时记“不可评估/探索性”，不补造走神、压力或情绪标签。
[ ] 模型版本、通道、采样率、单位、预处理与时标契约匹配；需原生REC时钟的模型不据普通LSL强行在线启用。
[ ] 相对指数、真人模型估计、本人自评与质量状态分别保存；反馈依据哪一种信号明确记录。
[ ] 导出校验值通过后再交给Studio训练；原始脑电单独保管，不随普通软件包分发。

六、冻结后的独立验收
[ ] 在开发数据内固定预处理、特征、模型、校准与阈值；测试参与者未用于任何选择。
[ ] 对比匹配的无EEG模型与融合模型；同一测试人、探针、历史标签和校准预算。
[ ] 重戴、跨天、新人和新任务分别统计；按人给出区间、覆盖率和逐样本预测。
[ ] 现场记录持续运行、掉线恢复、输出缺失与端到端延迟；计算耗时不当作状态响应时长。
[ ] 反馈效果另按CRED-nf方案做匹配对照，保留独立行为结局和实际有效反馈时长。
