凝思试采套件 · pilot-20261114-r3 · Windows x64

将整个 ZIP 解压到本机可写目录。两个 EXE 都可以直接运行，无需安装 Python。

第一次真机试采

1. 在设备厂商软件发布 LSL 脑电流。双击 NingsiCapture.exe，在“参与者与协议”填写匿名编号（例如 PILOT001）、到访编号（例如 01），选择“预试”“LSL 真机”。短版试采请选择“短版研究协议（18～20 分钟）”。默认选中“完整研究协议（45～50 分钟）”。
2. 在“设备与单位”点“发现 LSL 脑电流”。核对厂商的原始 EEG 流、通道顺序、电极标签、参考电极和输出单位。出现多个候选时按设备名称、主机和来源标识选择。ADC 计数需填厂商提供的 µV/计数倍率。声明单位与所填倍率冲突时程序会提示并停止，重新选择单位后再开始。单位未知时可仅保存原始和行为数据。
3. 选择保存位置，点“开始连续采集”。等样本持续增加、波形更新至少 4 秒，点“打开受试者任务窗口”。此时程序用导出时相同的质控检查最近 4 秒。首次试采若提示平线、时钟未同步或单位未确认，点“否”，调整电极、检查发布端或停止后更正单位，再次检查。任务开始后窗口保持前台。短版任务约 18～20 分钟，另留佩戴、说明和导出时间。练习探针不限阅读时间。
4. 任务窗口显示“实验已完成”后，点“停止并保存本次采集”，再点“导出本次采集”。选择导出父目录，记下程序提示的新导出目录。原始记录和导出目录都要保留。重新导出可用“导出已有记录”选择含 recording.sqlite3 的目录。
5. 双击 NingsiStudio.exe，在自动打开的平台进入“更多工具 → 模型训练”。将上一步的新导出目录粘贴进“本机采集目录”，点“导入并验收”。也可用文件夹选择框。复查基线时打开导出目录中的 baseline.json 和 export.json。
6. 在 Studio 核对协议名称、非练习探针总数、能提取脑电特征的探针数及有效二分类回答数。短版完成应有 15 个正式探针，完整版应有 32 个，两种协议各有 1 个练习探针。预试组的开发和测试计数应均为零。若特征大面积缺失，查看 features.csv 的 unavailable_reasons 及 windows.csv 的 reasons，再核对设备单位、基线和时钟。

短版流程为睁眼校准 120 秒、独立静息 45 秒、24 次 SART 练习、探针练习和 3 个正式区块。每块 115 次刺激，其中有 13 次 No-Go，另有 5 次正式探针。区块间各休息 45 秒。需要 PVT 前后测和动作对照时请选择完整版。

正式采集与训练

1. 正式采集前指定“开发组”或“独立测试组”。同一人的所有到访使用同一匿名编号和同一组，预试人员保持预试。练习和模拟采集使用独立编号。
2. 把同一研究中各次导出放在共同的父目录。Studio 每次导入形成一份数据集快照。开始训练时选包含全组导出的父目录，或在采集器点击“合并训练数据”后选择新生成的 dataset 目录。
3. 在 Studio 导入并验收。至少需要 5 位有效开发参与者，各训练折需同时含“当前任务”和“内部走神”，独立测试组也需有两类有效标签。符合条件时点“一键训练与独立评估”。系统按人分折，先冻结模型，再评估封存测试组。
4. 完成后预览报告、下载完整成果 ZIP。要在新会话加载同一版本，点“启用此模型（新会话）”。把原始记录、导出和训练成果保存在研究数据目录。

没有设备时可在采集器显式选择“模拟演示”与“快速模拟联调”练习操作。模拟数据只用于检查流程。关闭 Studio 控制台可停止平台。两个程序默认分别在 EXE 旁的 var\capture 与 var\studio 保存数据。

本包版本和逐文件 SHA-256 见 BUILD.json 与 SHA256SUMS.txt。压缩包同目录有 .zip.sha256 校验文件。使用 Windows PowerShell 的 Get-FileHash 命令可以核对下载或复制后的 ZIP。
