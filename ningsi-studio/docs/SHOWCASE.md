# 历史展示模块开发说明

2026-11-17 产品导航调整后，该模块已从正式前端入口与路由移除，旧 `#/showcase` 地址会回到开始评估。源文件及分析接口保留供开发核对，不再作为用户使用流程。以下记录原有模块能力与数据约定。

## 展示顺序

| 画面 | 可操作内容 | 对应要求 |
|---|---|---|
| 设备采集 | 扫描设备与查看状态，填写型号、厂家、电极、参考、采样率、单位与资料出处，保存核对资料 | 实际硬件、单通道及以上实时采集、单位与时间依据 |
| 预处理 | 选择干净、眨眼、肌电、运动或混合模拟，运行计算；查看原始、仅滤波和污染留空曲线及前后 PSD | 漂移校正、带通、工频处理、伪迹处理与质量门控 |
| 特征 | 查看 θ、α、β 的绝对与相对功率、时域特征、有效覆盖、逐窗状态与指数 | PSD、时域、生理解释与相对个人基线 |
| 模型 | 运行显式仿真训练并查看划分指标；进入真人数据导入、独立测试与模型启用 | 可训练、可部署模型 |
| 联合报告 | 选择已有会话或运行完整模拟，查看脑电、量表、行为证据、报告与建议 | 联合评估、结构化输出与缺失／冲突处理 |
| 历史反馈 | 展示所选会话的热力图、周月趋势、预警与训练结果，并进入完整页面 | 实时结果、历史查询、趋势和反馈干预 |

首次没有会话时，可以显式运行完整模拟会话。模拟使用单独的演示参与者编号、仿真 EEG 与确定性模拟作答，按正常状态机生成真实软件产物；它不会进入真人训练数据，也不替换已启用的真人模型。运行期间可以在会话流程查看进度，结束后查看联合报告和反馈。模拟记录不用于压力自评趋势。

## 原始信号导入

预处理画面接受本地 JSON 文件，文件上限 1 MiB。最小结构如下，实际样点需至少覆盖六秒，数组顺序为「通道 × 时间」：

```json
{
  "mode": "raw",
  "rate": 250,
  "scale_to_uv": 1,
  "channel_labels": ["Fp1", "Fp2"],
  "samples": [[0, 1, 2], [0, 1, 2]]
}
```

示例仅说明字段，三个点不足以运行。`scale_to_uv` 必须来自已确认的电压单位或 ADC 标定；例如输入已经是 µV 时为 1。可附加与样点一一对应的 `timestamps`。没有源时间戳时界面明确标注为按标称采样率回放，不能证明设备时钟正确。

需要相对指数时，另提供同设备、同导联、同单位的 `baseline_samples`，可选附 `baseline_timestamps`。基线必须独立于任务记录并达到现有质量与有效时长门槛。没有合格基线时仍显示波形、频谱和质量诊断，指数保持缺失。

导入分析不修改源文件，不自动加入研究数据集。最新四秒用于波形和频谱画面，逐窗序列按两秒步长计算；滤波另使用两秒历史。处理耗时、输入跨度、更新周期和滤波延迟分别显示。

## 伪迹与结果解释

滤波曲线展示漂移、带通和工频处理的实际结果。污染标记来自现有眼动样、肌电样、运动样和信号故障检测，处理后曲线将疑似污染点留空，含污染的整窗不评分。留空与拒评不表示重建出了干净 EEG。有同步 EOG 参考的生产采集路径可进行眼电回归校正，普通双前额 EEG 不自动成为 EOG 参考。

三个 0–1 指数描述相对个人基线的变化。仿真分类器的准确率仅检验模拟数据链路。压力和情绪公共候选仍是研究分数；已有压力周月趋势来自本人当下自评。页面不会用这些结果替代目标设备的独立验收。

## 设备资料与证据

设备核对资料保存在当前 Studio 数据目录的 `showcase/device_profile.json`。资料保存为操作员声明，不自动签发合规或标定结论。资料出处仅存为文本，服务器不会按填写的路径读取文件。

验证证据接口只读取固定的本地汇总来源，返回窗口数、合格数、基线与配对情况等摘要。发行包使用脱敏开发快照时会明确标注快照来源和日期；缺失证据显示未提供，现场重新采集与验收仍需独立完成。
