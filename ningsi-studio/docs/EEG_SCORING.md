## 2. 什么叫“可用窗口”

| 层次 | 当前实现 | 能说明什么 |
| --- | --- | --- |
| 完整信号窗 | 4秒、2秒步进；250Hz时每通道至少1000点；数据全部有限 | 样本足够进行频谱计算 |
| 严格合格窗 `usable` | 全通道通过下表门槛 | 通过现有伪迹代理粗筛，尚不能保证是真实无污染脑电 |
| 可评分窗 | 严格合格＋有效睁眼基线＋采样率/通道数与基线一致＋完整指数 | 能计算相对基线的工程指数 |
| 十分钟训练A级 | 严格合格且每通道两个2秒片段都通过额外片段筛查 | 可以在有效基线条件下用于探索性训练反馈/描述性汇总 |
| 十分钟训练B级 | 至少保留部分通道片段 | 描述频带和质量反馈；不计注意力奖励，不进入完成页指数 |
| 十分钟训练C级 | 没有可保留片段 | 固定引导，不生成脑电奖励 |

严格门槛作用于真实设备调理后的信号：逐通道去直流、0.5Hz高通、50/60Hz陷波、45Hz低通；显式仿真不经过该真机调理。任一通道违规即拒绝整个窗，多通道平均不能掩盖坏通道。

| 检查 | 通过条件 |
| --- | --- |
| 绝对幅值 | 所有点≤150µV |
| 平线 | 每通道标准差≥2µV |
| 通道差 | 同一时刻最大通道差≤100µV（不是单通道峰峰值） |
| 高频代理 | 每通道30–45Hz相对功率≤35% |
| 低频代理 | 每通道0.5–4Hz相对功率≤55% |

频带代理只用于粗筛，低频偏高不能直接确诊眼电。片段筛查另拒绝极大值或极小值重复占比≥10%的2秒片段。所有这些门槛都是待验证的工程设置，本次未放宽。

真实流还检查末次收样新鲜度（默认超过3秒返回空窗），按声明采样率取样点。当前新鲜度门控不等于逐样本时间戳连续性证明；采样率误报、少量丢包、短暂停顿和滤波残余仍需设备验证。不能仅凭“窗口通过”认定采集充分可靠。

## 3. 基线有效条件

只使用严格合格窗，且以下条件同时满足：至少5窗、窗口时间区间并集覆盖至少30秒、严格合格窗比例至少60%、通道和采样率等配置一致。重叠和重复窗不重复累计有效时长；基线前后半段差异仅记录为诊断，没有经过验证的稳定性合格阈值。

任务态参照睁眼基线，闭眼基线独立记录。十分钟协议训练前采60秒睁眼基线，前后基线采集均剔除跨越阶段起点的滚动窗；60秒内的覆盖不能被算成超过60秒。

2026-11-13流程修复后，完整/短协议也剔除跨阶段滚动窗。普通采集在各间隔末读取；完整协议训练后基线安排32秒，留出建立完整滚动窗的余量，有效覆盖门槛仍为30秒。

## 4. 专注相关指数怎样计算

Welch使用4秒分析窗、2秒Hann分段、分段50%重叠，多通道先平均功率谱再求频带功率比。三个候选特征分别为自然对数 `log(β/θ)`、`log(α/β)`、`log(θ/α)`，频带为θ 4–8Hz、α 8–13Hz、β 13–30Hz，功率下限1e-6。

令特征为x，参照位置为m、尺度为s：

```text
scale = max(s, 0.10 × |m|, 0.15)
z = clip((x - m) / scale, -3, 3)
score = 1 / (1 + exp(-1.1 × z))
```

完整/短协议的m/s为合格基线窗的均值/样本标准差；十分钟协议为中位数/1.4826×MAD。基线位置对应0.5；经过z截断，实际可达值约0.0356–0.9644。0.8表示相对当次基线的较高指数，不表示80%概率、80分能力或训练提升80%。

完成页按符合条件的训练窗等权计算未平滑指数均值；包括连续3窗升级等待期间已有的A级有效分数。实时奖励另经过0.3×当前＋0.7×此前的平滑，并由反馈门控控制，因此不能混用这两个均值。降级立即、升级连续3窗、每轮重置；B/C级不计奖励。

## 5. 专注维度的评定

完整/短协议的联合评定要求睁眼基线有效、监测指数存在且监测严格合格比例≥60%；脑电“低专注”工程阈值为均值<0.40。SART独立查看虚报率>10%、漏报率>10%或反应时变异系数>0.30；PVT查看有效任务的慢反应率>10%或漏答率>10%。无效或未完成的行为任务不进入联合评定；脑电与行为方向不同则标注不一致。

十分钟协议未采集独立monitor，所以联合评定中脑电明确为“未采集独立监测阶段”，训练描述性均值不填入脑电测评证据。PVT正式成绩独立保留，练习不计入正式成绩。它可以提供行为警觉性证据，不能单凭训练指数下全面专注能力结论。

当前PVT主慢反应阈值仍为>500ms，另保留≥355ms对照。它们及10%判定阈值都没有在本产品的浏览器/设备/目标人群完成常模验证。v3另要求有效反应≥5次、占全部试次≥60%、抢答比例≤25%、无非法反应时、任务完成；不满足时保留成绩但不进入联合评定。这些新增条件也是待验证的工程完整性规则。

训练统计升级为`neurofeedback-v3`：每个有效反馈最多覆盖随后2秒，在下一事件、无效标记或段末截断。分别给出有效时间/整段时间、达标时间/有效时间和达标时间/整段时间。无效时间点明确打断连续保持，长缺口不补齐；覆盖不足60%时不调整目标，提高目标还要求达到连续保持时长。旧记录按有效样本计算的占比保留旧版标记，不能与新版整段时间占比直接比较。

联合评定升级为`joint-assessment-v3`：单个PVT或者多个脑电指标不能称为多来源一致。无阈值触发时写“未触发工程阈值”，单一来源触发时注明来源和缺少交叉验证，不输出“正常范围”或个人能力等级。

## 6. 文献边界与验证范围

[Wei等，2024，原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10968630/)区分了主观注意控制信念和客观任务表现，并发现比值关系依赖睁眼/闭眼与导联。对本产品的含义是：β/θ可以保留为探索性候选特征，不能由该研究推导本软件的个人评分映射或0.40阈值已经有效。

[Basner等，2011，PVT-B原始研究](https://pubmed.ncbi.nlm.nih.gov/22025811/)比较3分钟与10分钟PVT并考察355ms和500ms阈值；该研究不能直接验证本产品浏览器任务的计时、阈值或个体诊断效力。

本次验证覆盖旧会话只读恢复、全流程仿真、全平线降级、前端渲染、基线去重覆盖和无效行为排除；真人真机的测量效度和阈值验证仍需独立完成。
