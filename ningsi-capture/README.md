# 凝思独立实验采集器

三包职责、处理策略与训练衔接见[系统架构](../docs/ARCHITECTURE.md)，现场与研究指标见[技术验证计划](../docs/VALIDATION_PLAN.md)。整仓软件检查可在根目录运行 `scripts/verify.ps1`。

这是连接现有脑电硬件的 Windows 桌面程序，用于真人专注指标验证实验。它独立启动、独立保存数据，不需要启动 Studio 服务，也不读取或改写 Studio 的会话数据库。Windows EXE 已包含算法引擎、NumPy、Tk 和 LSL 运行库。

## 启动与采集

使用试采套件时，在解压目录双击 `NingsiCapture.exe`。从源码运行可使用采集器目录的 `run.bat`，依赖 Python 3.11+、NumPy、pylsl 1.18.2、Tk 和同级的 `../ningsi/src` 算法引擎。

1. 在「参与者与协议」填写匿名编号、到访编号和预先分配的组别。编号只用字母、数字、横线、下划线。复测沿用同一参与者编号，修改到访编号，并保持组别一致。
2. 真机选择「LSL 真机」，在「设备与单位」点击「发现 LSL 脑电流」。先用设备厂商程序发布 EEG 流，再选择与实际设备对应的流。程序不自动退回模拟源。
3. 核对源单位、电极标签与参考电极。V、mV、uV 是明确的单位转换；设备输出 ADC 计数时，必须输入经设备说明或校准确认的 `µV/计数` 比率。未知单位允许记录原始数据，但不会生成有效训练特征。未声明电极位置时显示 Ch1、Ch2，不假定为 Fp1、Fp2。
4. 选择保存位置，点击「开始连续采集」。原始文件从这一刻持续写入，任务切换和探针回答不会中断录制。
5. 收到至少 4 秒新鲜样本后可以打开任务窗口。预试即使单位或时标待确认也可记录任务、按键和作答，质控原因随事件保存，预试始终排除在训练和测试集之外。常规开发组、测试组须先通过最近一窗的 EEG 质控。使用 BioMulti 原生双录时，设备对时和最终质控在导出时完成。F11 可切换全屏。
6. 操作台和受试者窗口同步显示阶段序号及本段已用时间（分:秒）。基线、休息、光点反应和动作对照显示倒计时。数字任务按剩余试次、探针作答时限和恢复时间估算剩余时长。练习探针不限时，作答后继续。
7. 完成任务后点击「停止并保存本次采集」，再「导出本次采集」。关闭任务窗口前会确认是否中止。失去任务窗口焦点、信号超过3秒未更新会中止实验并保留数据。操作台同步显示具体原因。停止采集后才能重开一个新实验，避免同一记录里重复的基线与探针身份。

本机 BioMulti Lite 1.0.9-E-Release 的双通道 250 Hz EEG 在发现后默认选「BioMulti 自动」。可直接开始连续采集。若先在厂商软件点 REC，凝思还会绑定原生记录，日志显示编号。两边录完保存后，导出按设备包号和时钟复核。

两个通道明确声明相同电压单位时，采集器优先采用声明。本版本的官方软件用解码后的 EEG 去直流并计算以 µV²/Hz 标注的功率谱，LSL 发布器直接复制同一组解码样本。对于本机匹配该版本、名称和配置且未声明单位的流，凝思按 µV（倍率 1）计算，记录 `unit_basis=biomulti_software_inference`。这一换算来自软件和同期样本的推断。已知校准值可以手动选择，亦可选择仅保存原始。

官方发布器每包发送 10 个样本，没有向 LSL 传递设备时间。凝思使用包内 4 毫秒间隔和每秒低延迟包的发布时间估计采样时间。对较长发布间隔，最多再观察 1 秒后续包的到达情况。包内样本不符、跨包时钟重置、超过 250 毫秒的发布间隔或未追回的长间断会产生无效时间。实时探针只使用提示时已收到的数据。无 REC 时可获得估计时钟，无法逐包验证所有丢包或测量绝对延迟。导出中的 `packet_timestamps.npy` 按原始样本索引保存估计时刻，未确认的区间和末尾不足 1 秒的部分为 NaN。配对 REC 的导出使用设备时刻。旧版同机记录重新导出时也能应用这些规则，`source_at_capture` 保留采集时的配置。

采集器按 BioMulti Lite 1.0.9-E 的原生格式，从本机 data.db 读取所绑定的记录。它比对每个包内两路全部十个样本，使用唯一匹配的包号、设备毫秒时钟和同期 LSL 时钟估计事件对齐时间。导出的 `device_packets.csv` 和 `device_timestamps.npy` 记录匹配和估计，`export.json` 给出覆盖数及锚点残差。包缺失、重复或时钟异常的上下文不能产生合格脑电特征。原始文件保留厂商发布的时间戳。该方法尚未测量硬件采样到刺激呈现的绝对延迟。双录的实时模型预测标为待核对，保留当时实际可用的结果。

已保存的两份旧记录可用 `NingsiCapture.exe check-clock 采集目录 --rec-id 编号 --output 核对.json` 只读检查。使用 `export 采集目录 --out 新目录 --rec-id 编号` 可导出双录分析。若厂商数据库已随记录迁移，可用 `--biomulti-db 文件路径` 选择它。跨电脑处理前请保留与本次采集配对的原生 REC。程序只导出本次匹配的 EEG 包信息。

如需复现早期软件的处理方式，可在新建采集时手动选择「分包时标兼容（限 50 毫秒）」。该选项逐窗估计时标，超过 100 毫秒的源间隔会使窗口质控失败。

首次请用「模拟演示」和「快速模拟联调」练习操作。模拟源必须显式选择，快速联调不能用于真实 LSL 研究任务。模拟记录和明显声明为模拟的 LSL 流均不会进入真人训练集。LSL 软件连接本身不能证明信号来自真人，实验员仍须核对采集设备和发布程序。

## 实时质控与随机探针预测

### 0.4.0 脑电预处理

开始连续采集后，操作台默认显示「处理后 · µV」。在样本计数右侧可选择「原始 · 源数值」或「仅滤波 · µV」。仅滤波视图用阴影标出疑似伪迹，处理后视图将屏蔽时段留空。处理图每两秒更新最近的完整四秒窗，各通道分别自动缩放，幅度标在图中。单位、时标或两秒滤波历史不足时显示等待原因。原始波形与任务事件可持续记录。

输入按来源倍率换算为 µV。每个输出样本使用截至当时的两秒输入。软件做 0.8 Hz 高通漂移校正、42 Hz 低通，在奈奎斯特频率内启用 50 和 60 Hz 陷波。θ 为 4–8 Hz，α 为 8–13 Hz，β 为 13–30 Hz。42 Hz 低通自身约有 180 ms 延迟，总延迟随频率变化。导出保留输出采样时刻和原始事件时刻。BioMulti 原生界面与 LSL 可能提供不同的显示信号，硬件滤波配置以实际设备为准。

四秒窗内还检查局部慢波大幅偏转、30–45 Hz 肌电样爆发、采样率允许时的 66–94 Hz 宽带爆发、运动样跳变和通道停滞。两路 EEG 提供的是伪迹线索。疑似片段在处理图和导出中置为空值，含伪迹的整窗退出特征计算，避免用插补或过度平滑的数据训练。工程阈值尚需独立标注验证。原始样本保存全部通道。

新版正常导出包含 `cleaned_windows_uv.npy`（窗 × 通道 × 采样点）和 `artifact_mask.npy`（窗 × 采样点）。两者逐行对应 `windows.csv` 的 `sample_end_index`。掩码可按位叠加，1 表示眼动样，2 表示肌电样，4 表示运动样，8 表示信号故障或未定位的整体质量异常，16 表示时标、单位、历史长度等原因导致无法处理。值为 0 的样本仍须结合整窗 `usable` 选用。逐窗表含原始和处理后 50/60 Hz 功率占比，`export.json` 记录方法与版本。

操作台「导出已有记录」会用新版预处理复算到新目录。命令行复算旧记录时在 `export` 后附加 `--reprocess`，省略该选项可复现原采集版本的处理方式。做真人模型训练时，同一批开发和测试记录统一使用一个处理版本，Studio 按训练时的版本提取实时特征。随包的冻结公共候选沿用其原训练滤波。

0.3.5 在操作台显示滤波前每个四秒窗的 50 Hz 工频占比和最近 14 窗的合格率。推荐在打开受试者窗口前安静观察约 30 秒，核对实际电极、参考和分组。工频比例由前两路分别计算，分子为 49–51 Hz，分母为 1–100 Hz（上限取奈奎斯特频率），按标称采样率计算去均值 Hann 窗功率。超过一半时显示检查接触与线缆的提示。该比例不参与现有训练资格判断，原始时间和信号继续写入。

操作台显示基线的合格数、比例和覆盖秒数，以及当前区块和全场正式探针的脑电与回答配对数。导出完成后可查看实际开发行、独立测试行和两类自报计数。逐窗工频结果见 `windows.csv` 新增的 `raw_50hz_ratio_ch1`、`raw_50hz_ratio_ch2`（若有第二路），正式探针汇总见 `export.json` 的 `training_readiness`。完整现场步骤见同目录的《使用说明》。

操作台上的实时质控按每 2 秒一个 4 秒窗更新，显示未通过的原因和可定位的电极读数。睁眼校准完成后会显示基线是否通过。进入正式 SART 后可核对本区块的已提示数、有合格脑电的探针数，以及同时取得合格脑电和二分类回答的探针数。基线和区块统计使用采集导出的质量口径。

### 250 Hz 双模型与任务时间对照

0.3.0 随包冻结了逻辑回归和 RBF 核岭回归两个候选。正式随机探针出现时，后台锁定当时已经收到的脑电。两者取提示前 18 至 2 秒内的 4 秒窗，步长 2 秒，每窗使用截至窗尾的最多 6 秒信号进行滤波，按 Fp1−Fp2 计算同一组 6 个频谱特征。设备需标称 250 Hz，两支电极位置和源单位须已确认。训练使用公开健康对照的原始双通道和物理质控，250 Hz 来自公开 512 Hz 波形的抗混叠重采样。候选输出为未经本地校准的走神分数。

打开 **`probe_comparison.csv`** 即可将这两组分数和任务时间逐探针对齐。按 `participant`、`visit`、`session_id` 区分人员与场次，同一人的多次到访应分在同一训练或测试组。

| 导出列 | 含义 |
| --- | --- |
| `task_elapsed_sec`、`probe_ordinal` | 从第一个正式 SART 区块开始到该提示的经过秒数，含区块间休息；正式探针从 1 起跨区块连续编号 |
| `protocol_elapsed_sec` | 从整个协议开始到该提示的经过秒数 |
| `logistic_mw_score`、`rbf_mw_score` | 逻辑回归与 RBF 的连续分数，数值越高表示模型越倾向于走神 |
| `choice`、`choice_text`、`response_status`、`label` | 原始作答、选项文字、作答状态和可用的本地二分类标签 |
| `comparable` | 正式探针取得两组分数和可用二分类回答，可进入同探针对照 |
| `time_comparable` | 正式真人研究探针具有二分类回答、时间和序号；可作为计算脑电评分覆盖率的分母 |

同一行还记录模型标识、提示前评分区间、算分时的物理质控、严格质控及该提示时的实时脑电质量。算分使用两路输入及差分的物理质量条件，至少 3 个合格窗、时间并集至少 6 秒、合格比例至少 60%。严格质控另外筛查眼动和肌电频带代理，因此严格质控提示异常时，候选仍有可能打分。各窗可向前取最多 2 秒用于滤波预热，最早到提示前 20 秒；提示前最后 2 秒及答案均不参与打分。缺失的分数和标签留空；旧采集文件没有现场预测时会标记 `not_recorded`。

比较脑电增益时，在相同的 `comparable` 探针和相同的按人划分上，分别比较仅用时间和序号、再分别加入一个模型分数的结果。每位有两类回答的人先算个人 AUROC，再对人取平均。同时保留全部正式探针，统计可评分比例、未回答数量和拒评原因。随机提示和受试者作答均独立于后台分数。

### 原版 ATTLAPSE 候选

ATTLAPSE 外部候选模型只在后台对既定的正式随机探针评分。请按实际佩戴位置核对 Fp1、Fp2 标签和电压单位，两支电极应使用共同参考。模型取探针前 12～2 秒的 Fp1−Fp2 双极脑电，要求本次独立睁眼基线有效，并检查原通道和双极信号的窗口质量。软件保留模型版本、当时已到达的样本数量、时间范围、分数或缺失原因。模拟或练习记录可用于观察质控流程。受试者任务界面只显示原协议的问题和选项。

导出后用表格软件打开 `probe_predictions.csv`。每行对应一个探针，`mw_score` 为候选模型的走神分数，`choice` 为受试者原始回答，`label` 为本地二分类标签（回答 1 记 0，回答 3 或 5 记 1）。`comparable=True` 表示两者都可用，`agreement` 比较固定阈值 0.5 下的预测类别与该回答。`status`、`reason`、`response_status` 解释因信号或作答而无法比较的行。旧记录显示 `not_recorded`。记录级计数见 `export.json` 的 `probe_predictions`。模型分数用于研究对照，准确性和校准需在本地设备与新参与者上验证。

模型使用 Horáková 等发布的 [ATTLAPSE v2.0.1](https://doi.org/10.5281/zenodo.23592484) 健康对照原始 EEG 与探针回答。源任务区分任务中、自发走神和有意走神，训练合并了后两类。公开录制另带四个眼电电极，训练时用探针前 18～2 秒的垂直、水平眼电差分对前额脑电作线性伪迹校正，再按上述时间窗和质量要求提取六维谱特征。本机双通道设备仅用实采脑电，在原通道和双极通道上进行质量检查。源数据缺少可确认为本地协议睁眼基线的记录，现场另做基线校准。

从源码复算时，在仓库根目录运行下列命令。下载器按参与者校验脑电与事件文件，可以重试。训练输出包含模型、逐探针特征和按人五折的验证报告。

```powershell
.\.venv\Scripts\python.exe ningsi-capture\scripts\attlapse_data.py var\attlapse --with-aux
.\.venv\Scripts\python.exe ningsi-capture\scripts\train_attlapse.py --data var\attlapse --output var\attlapse-reproduction
```

## 选择任务协议

真机采集可选择「短版研究协议（18～20 分钟）」或「完整研究协议（45～50 分钟）」。默认选中完整版。时间从打开受试者任务窗口开始计算，佩戴设备、检查信号和导出另计。练习探针可按自己的速度阅读，实际总时长随回答速度变化。

### 短版研究协议

睁眼校准 120 秒 → 独立静息 45 秒 → 24 次 SART 练习和 1 次练习探针 → 3 个正式 SART 区块。每块有 115 次刺激，其中 13 次为数字 3，另有 5 次正式探针。区块之间各休息 45 秒。正式探针共 15 次，每次最多等待 8 秒，随后恢复 1 秒。刺激间隔为 2.2 秒。第三个区块结束即完成任务。

短版编号为 `attention-validation-short-v1`。配套 Studio 在导入时显示协议和采集次数，并沿用相同的基线、脑电质量、标签及预分组规则。需要前后 PVT 和动作对照时选完整版。

### 完整研究协议

| 阶段 | 设置 |
| --- | --- |
| 睁眼基线 | 120秒，只有该阶段进入个人基线 |
| 独立静息记录 | 120秒，不参与基线计算 |
| SART练习 | 12试次，练习探针独立记录；读完七个选项并作答后继续，不设阅读超时 |
| PVT练习 | 30秒，不计入正式数据 |
| PVT前测 | 180秒 |
| SART正式 | 4区块，每块180试次、20个No-Go，数字3不按键，其余按空格；固定2.2秒SOA |
| 正式随机走神探针 | 每区块8次，按1–7回答，最多等待8秒；探针结束后1秒恢复，区块间休息60秒 |
| PVT后测 | 180秒 |
| 动作对照 | 静坐60秒；眨眼、轻微下颌/皱眉、小幅转头各20秒，每次动作后休息10秒 |

各区块的数字序列、No-Go位置、探针位置和随机种子保存到事件文件。不同参与者和到访编号产生各自的序列。SART刺激保持完整2.2秒，按键不会提前进入下个试次。PVT使用作答/超时后随机1–4秒等待的研究变体，刺激后最多等待3秒；保留早按、漏答、无效试次和500ms慢反应标记，不声称与临床PVT或PVT-B等效。

### 走神探针与标签

问题固定为「提示出现前约10秒，你的思维主要在哪里？」：

| 回答 | 含义 | 主分析标签 |
| --- | --- | --- |
| 1 | 正在处理当前任务 | 0 on_task |
| 2 | 评价自己的表现或想着任务何时结束 | 保留原回答，不进入二分类 |
| 3 | 想个人生活中的事情 | 1 internal_mind_wandering |
| 4 | 被环境或身体感觉吸引 | 保留为外部干扰 |
| 5 | 想象、白日梦等任务无关事情 | 1 internal_mind_wandering |
| 6 | 脑子空白 | 保留原回答 |
| 7 | 不确定 | 保留原回答 |
| 超时或中止 | 未取得有效回答 | 缺失，不推测标签 |

## 连续原始数据与时间

每次采集创建唯一目录，`recording.sqlite3` 是原始记录，`manifest.json` 保存元数据。SQLite启用WAL及FULL同步，每收到一批样本即提交，不依赖最后点击保存。采集异常会保留已提交的数据。实际掉电下的存储保证仍取决于文件系统、磁盘和设备；本程序没有验证物理掉电可靠性。

原始值按小端float64二进制保存，不滤波、不转换源单位、不抽稀、不插值、不删除重复时间戳。float32等LSL输入转换为float64可精确保留其数值；这不是设备无线包或ADC字节流的备份。非有限值保留在二进制数据中，但不进入特征计算。

真实LSL inlet使用 `processing_flags=0`，不覆盖源时间戳。同时记录：原始源时间、原始时间戳的二进制表示、LSL校正后的本机时间、批次接收LSL时间、接收Python高分辨率时间、定期LSL时钟偏移及失败原因。每秒另存一对Python/LSL时钟读数。连接中断不静默切换设备或重连到新流，需要新建采集。

刺激时间由Tk完成空闲绘制后的软件时刻估计，原始按键回调同时记录OS事件毫秒值及Python/LSL时间。它们不是光电二极管测得的屏幕亮起时刻，也未扣除键盘硬件延迟。正式研究前需用实际设备完成显示、键盘、时钟漂移与丢流验证。重叠分析窗口、探针和试次不是独立参与者。

### 特征口径与排除

离线分析逐通道按明确的倍率转换到µV，仅用截至窗尾的最多6秒历史信号进行去直流、0.5Hz高通、50/60Hz陷波、45Hz低通，取最后4秒计算原引擎Welch与严格质量规则。原始文件不改变。另拒绝未校正、非有限或非单调时间戳、超过100ms的时间间隙、与声明采样率相差超过5%的窗口，以及低于100Hz的特征计算；这些额外门槛是待设备验证的研究采集完整性设置。

基线采用完整协议的均值/标准差口径，保持引擎至少5窗、去重覆盖至少30秒、严格合格比例至少60%的条件。校准段结束后的独立静息和任务数据不会进入基线。

每个探针取提示前 `[-12,-2]` 秒内完全包含的窗口，至少3个严格合格窗、时间并集至少6秒、合格窗比例至少60%，并要求整个回看区间位于同一SART阶段。窗口等权汇总。保留六维特征 `rel_theta, rel_alpha, rel_beta, log_beta_theta, log_alpha_beta, log_theta_alpha` 与未平滑的 `focus`、`focus_z`。三组对数比值存在代数依赖，不能将每个回归系数独立解释为因果机制。

信号可计算与标签可用分开：回答2/4/6/7仍可保留有效脑电特征，但不会被硬凑为0或1。练习、模拟、非正式协议、不完整协议/记录、无有效基线、标签缺失或引擎指纹发生变化的记录，不进入默认真人模型训练或测试。软件标记和质量通过不能证明测量效度。
